# EntryLens 安装与使用指南（v0.1.0-beta）

> 适用：Legado 3.x（Android 8.0+）
> 前置知识：Legado 的"替换规则"与"适配特殊样式"功能

## 1. 原理简介（30 秒版）

Legado 阅读页正文是**自绘渲染**，无法注入 JS 操作 DOM。EntryLens 改用官方能力：

1. 一条**替换规则**（正则匹配整章 → `@js:` Rhino 脚本）扫描章节文本；
2. 识别出面板/系统提示/任务奖励/数值增减后，把对应段落改写成 `<usehtml>` HTML 段；
3. Legado 的"适配特殊样式"功能把 HTML 段渲染成带颜色/加粗/下划线/分隔线的增强样式。

**原文 100% 保留**：所有增强都是给原文"穿样式"，不增删改任何字符。

## 2. 安装步骤（约 3 分钟）

### 2.1 导入替换规则

1. 把 `plugin/replace-rules.json` 传到手机（微信文件传输助手 / 网盘 / USB 均可）。
2. 打开 Legado → 我的 → **替换净化**（或 设置 → 替换规则）。
3. 右上角菜单（⋮）→ **从文件导入** → 选择 `replace-rules.json`。
4. 确认出现名为 `EntryLens 主规则 v0.1.0` 的规则（分组：EntryLens）。

### 2.2 前置开关（**默认已开启**，仅当以前手动关过才需检查）

**💡 这两个开关在 Legado 中默认都是打开的。如果你没改过相关设置，导入规则后直接生效，跳过本节即可。**

> 🚨 **排障提示**：如果正文里**直接显示 `<usehtml>` 代码**（如 `<usehtml><hr>【…】<hr><`），说明"适配特殊样式"没开——按下面第 1 步打开即可（替换规则本身已生效，只是渲染端没解析 HTML）。

1. **适配特殊样式**（必须，HTML 增强渲染依赖它）：
   - 精确路径：打开任意小说章节 → **点击屏幕正中央**（呼出顶部标题栏与底部菜单栏）→ 看底部菜单栏的 **四个按钮：目录｜朗读｜界面｜设置** → 点最右边的**齿轮"设置"按钮** → 在弹出的设置列表中**向下滑动**，找到 **"适配特殊样式"**（位置：在"中文排版 / 两端对齐 / 底部对齐"三个开关**下面**、"鼠标滚轮翻页"**上面**）→ 打开。
   - 该开关默认开启（`defaultValue=true`），只有以前关过才需要手动打开。
   - 开启后**重新进入章节**生效。
   - ❗ 别找错地方："界面"按钮（第二个）只改字体字号，不在这里；"我的 → 设置"里也没有这个开关。
2. **书籍启用替换规则**（必须，替换规则依赖它）：
   - 网络小说**默认启用**；仅**图片类书源 / 本地 epub** 默认关闭，需在书详情页设置里打开"Use replace"（启用净化替换）。
   - 全局兜底："我的 → 设置 → 其他设置 → 新书默认启用替换规则"（默认开启）。

### 2.3 验证生效

打开任意数值词条流小说章节，应看到：

- 面板类内容：名称带**稀有度颜色 + 下划线**，字段名灰、字段值正文色，上下有分隔线；
- 系统提示：单行小框，`提示：`/`警告：` 前缀标红；
- 任务/奖励/确认：大框 + 标题金色加粗 + 选项徽章 + 是/否按钮样式；
- 数值增减（如 `力量+5`、`HP-100`）：`+` 绿色、`-` 红色。

### 2.4 排障（不生效时）

| 现象 | 原因与处理 |
| ---- | ---------- |
| 完全没有样式 | ① 确认"适配特殊样式"开启（§2.2 路径）；② 确认书籍"启用替换规则"开启；③ 确认规则已启用（替换净化里开关是开的） |
| 只有文字没有颜色 | 可能是浅色主题下"白色"稀有度（`#C0C0C0`）不明显，属正常；换"绿色"装备验证 |
| 打开章节后原文消失了 | 不可能发生（渲染基于原文包裹）；若真出现请立刻禁用规则并反馈 |

## 4. 版本与渲染能力（重要）

Legado 阅读页的 HTML 增强渲染能力**因版本而异**（源码确认）：

| 样式能力 | 3.26.030717 及更早 | 3.26.071522 及以上 |
| -------- | :----------------: | :----------------: |
| 文字颜色（稀有度色/字段灰/警告红/+绿-红） | ✅ | ✅ |
| **字号缩小**（面板/提示内容 `<small>`） | ✅ | ✅ |
| **边框线**（`<hr>` 上下分隔线） | ❌ 不渲染 | ✅ |
| 加粗 / 下划线 | ❌ 不渲染 | ❌ 不渲染 |
| 字体切换（`font face`） | ❌ | ❌ |
| 底纹 / 背景色 | ❌ | ❌ |

- **推荐使用 3.26.071522 及以上版本**（legado-E 系列或官方新版），以获得面板/提示的上下边框线。
- 当前 v0.1.3 的面板/提示样式：**内容缩小字号 + 名称稀有度色 + 字段分级 + 上下边框线**（老版本无边框线但有字号与颜色差异）。
- "底纹/背景"与"字体切换"是 Legado 自绘渲染的硬限制，无法实现；加粗/下划线同样不渲染（颜色与字号是全部可用手段）。

## 5. 功能开关

| 想做什么 | 操作 |
| -------- | ---- |
| 总开关（停用插件） | 替换净化 → 关闭 `EntryLens 主规则` |
| 稀有度颜色自定义 | 编辑规则 → 替换内容里搜索 `#C0C0C0` 等色值，改成自己的颜色 |
| 只关数值高亮 | 编辑规则替换内容，把 `valueBold: 1` 改 0（后续版本提供独立开关规则） |
| 卸载 | 替换净化 → 删除 `EntryLens` 分组规则 |

> 设置即"编辑规则文本"是 MVP 方案（Legado 无插件设置 API）。v0.2 提供独立开关规则与配置导入导出。

## 6. 已知限制（MVP）

- **无弹窗**：Legado 自绘渲染没有弹窗 API，"点击名称弹窗"不可实现。面板以完整美化块直接展示（内容不折叠）。
- **无动效**：数值高亮无闪烁/渐变（无 CSS 能力）。
- **样式固定**：一套"深色游戏风"配色；浅色阅读主题下稀有度色仍可读（已选深浅通用色值）。
- **性能**：整章解析在 Node 基准 <1ms（Rhino 真机预计 <100ms，远低于 Legado 3000ms 超时保护）。
- **识别保守**：宁可不增强，不误增强；漏识别请收集原文反馈（见 §6）。

## 5. 真机冒烟清单（每次升级后约 5 分钟）

```
□ 导入新规则后，打开测试书源翻 5 页：无崩溃、无卡顿
□ 面板：稀有度色 + 下划线；无稀有度：正文样式 + 下划线
□ 面板字段：字段名灰、值正文色、提示/警告红、？？？保留
□ 系统提示：一行一框、前缀标红、字符完整
□ 任务/奖励大框：标题加粗、选项徽章、是/否按钮、不套稀有度色
□ 数值增减：+ 绿 / - 红
□ 乱排版/对话文本：完全无样式（降级正常），原文完整
□ 长按选择文字、复制：内容与原文一致
□ 截图存档（用于反馈）
```

## 6. 反馈问题（帮助调优识别）

把**原文摘录**（含上下文 2~3 行）发到项目 Issues：

- 误报：普通文本被套了样式（最需要，会加入反例集）
- 漏报：应该识别但没识别（会加入正例集）

## 7. 更新规则

替换 `replace-rules.json` 重新导入即可（旧规则删除或直接覆盖）。版本号见规则名与 CHANGELOG.md。
