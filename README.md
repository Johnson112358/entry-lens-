# entry-lens-
EntryLens：为数值词条流小说而生的 Legado 阅读增强插件。自动识别属性面板、装备、技能、系统提示，弹窗展示并支持稀有度颜色。EntryLens: A Legado plugin that brings game-like visual enhancements to stat-based web novels. Auto-detects attribute panels, equipment, skills, system prompts, and renders them with rarity colors and clickable popups.
